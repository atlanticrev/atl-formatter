# Как использовать `@atlanticrev/atl-formatter`

`atl-formatter` — это узкий форматтер для `js/jsx/ts/tsx`, который меняет **только пустые строки** по согласованным правилам.

## Что это даёт

- автоматически расставляет пустые строки между JSX-блоками
- добавляет пустые строки в нужных местах в функциях и хуках
- делает код визуально ровнее и одинаковым во всех проектах
- не трогает логику, имена, отступы и другой формат кода

## Установка

```bash
npm i -D @atlanticrev/atl-formatter
```

## Что запускать

### Проверить файлы без изменений

```bash
atl-formatter --check "src/**/*.{js,jsx,ts,tsx}"
```

Что даёт:
- показывает файлы, где не хватает пустых строк
- возвращает `exit code 1`, если есть проблемы
- удобно для CI и pre-push проверок

### Исправить автоматически

```bash
atl-formatter --write "src/**/*.{js,jsx,ts,tsx}"
```

Что даёт:
- сам добавляет нужные пустые строки
- приводит JSX/TSX и функции к одному стилю

## Как добавить в `package.json`

```json
{
  "scripts": {
    "format:blank-lines": "atl-formatter --write \"src/**/*.{js,jsx,ts,tsx}\"",
    "format:blank-lines:check": "atl-formatter --check \"src/**/*.{js,jsx,ts,tsx}\""
  }
}
```

## Когда это полезно

- перед коммитом
- в CI
- после обычного formatter-а вроде Biome
- когда нужно одинаково оформлять JSX и TSX во всех проектах
